## 各モード詳細

### 通常時

- 小役でストックを貯めて、CZ/AT抽選
- **高確率モード**: レア役成立時に移行、CZ当選率UP
- **天井**: 999Gハマりで強制AT突入

**主な小役期待度:**
- ドラゴンエッグ揃い → AT確定
- ネザースター揃い → AT+エンダーモード確定
- ブレイズロッド揃い → CZ高確率 + 高確移行
- エンダーパール揃い → CZ抽選
- チャンス目 → 高確確定 + CZ抽選

---

### CZ「竜の試練」

- 10G継続
- 勝利期待度を貯めてドラゴンに挑む！
- レア役で期待度UP、ラストゲームでバトル抽選

**勝利期待度UP:**
- ドラゴンエッグ揃い → 即AT確定
- ネザースター揃い → +30%
- ブレイズロッド揃い → +25%
- エンダーパール揃い → +15%
- ダイヤモンド揃い → +5%

---

### AT「ドラゴンラッシュ」

- 初期30G + 上乗せ
- 毎ゲーム上乗せチャンス
- ドラゴンエッグ揃いでエンダーモード突入！

**上乗せ性能:**
- ドラゴンエッグ揃い → エンダーモード確定
- ネザースター揃い → +20G
- ブレイズロッド揃い → +10G
- エンダーパール揃い → +5G
- プレミアム役 → +50G + エンダーモード

**引き戻し**: AT終了時5%で+30G継続

---

### RUSH「エンダーモード」

- 5G固定の超高確率上乗せゾーン！
- 毎ゲーム70%で+5G上乗せ（ハズレでも）
- 平均上乗せ: 約40G以上

**上乗せ性能:**
- ドラゴンエッグ揃い → +30G + 継続5G
- ネザースター揃い → +30G
- ブレイズロッド揃い → +20G
- エンダーパール揃い → +10G
- 虹演出（プレミア）→ +100G！

## 設置方法

1. プラグインの`slotConfigs`フォルダにこのフォルダをコピー
2. サーバーを再起動または `/slot reload` を実行
3. スロットマシンを設置:
   ```
   /slot set dragon_rush/normal.jsonc
   ```
4. ボタンを右クリックしてスロット開始！

---

## ItemFrame配置

```
[Frame1] [Frame2] [Frame3]  ← 額縁（リール表示用）
        [Button]            ← ボタン（操作用）
```

- 額縁はボタンの上に横並びで3つ配置
- ボタンは壁面に設置（上下面は非対応）

---

## 確率調整のヒント

設定を変更する場合は各JSONCファイルの`probability`値を調整:

- **緩くしたい場合**: 通常時のCZ抽選確率UP、AT上乗せ確率UP
- **厳しくしたい場合**: 天井を上げる、CZ失敗率UP
